# Projeto sistema de login

## Descrição
É um pequeno app feito Customtkinter, ele possui suas funcionalidade de verificar se a senha e usuario existem
e retorna login bem sugedido ou login incorreto, esse projeto foi feito com a intenção de aprendizado para aprender
a criar tela.

## Instrução de instalação

1.escolher a pasta de sua preferencia.
2. pegar o código abaixo com o git bash ou pegar a url em code do git hub.

```bash
clone git https://github.com/LucasValimPereira/projeto-sistema-de-login.git

```

## Instrução de uso

1. caso ter erro passar o código abaixo em algum terminal de uma ide de sua preferencia.
2. preencher os campos de usuario e senha.
3. usuario = lucas.
4. senha = admin123.
5. 
```bash
pip install customtkinter
```
